# 素材来源与公开边界

公开仓库收录本任务编写的安装器、资源打包代码、原生兼容补丁、文档和原创几何 SVG 示例。MIT 仅覆盖这些内容，不改变搜狗及任何第三方素材的许可。

原私有案例使用的「染上黍黍了」由 @陌芋marginal 创作。随包 `大人们请吃.txt` 写明原图与制作署名，并包含“可私下和朋友分享禁止倒卖，上传和商用”。因此本项目不上传：

- 原始 RAR、SSF、角色 PNG/GIF；
- 基于原图重绘、高清修复、抠图后的衍生素材；
- 含上述人物图像的预览或桌面截图；
- 搜狗原始资源 ZIP、核心动态库或安装包；
- 私有完整迁移包和个人配置、备份、日志。

用户可以在本地将有权使用的素材接入此工具。`build/` 中会包含从本机读取的供应商资源，因此它是本地生成物，并非默认可公开分发的 Release 资产。发布时只发布本仓库的源码文件。想分享某个主题时应单独确认它的素材授权，不能因代码是 MIT 就把所有图都标成 MIT。
